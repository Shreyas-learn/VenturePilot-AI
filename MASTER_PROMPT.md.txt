# IBM WATSONX INTEGRATION

The application MUST use IBM watsonx Python SDK.

Do NOT use Prompt Lab inside the application.

The application must communicate directly with IBM Granite through watsonx APIs.

The following values must be loaded using environment variables.

IBM_WATSONX_API_KEY

IBM_WATSONX_PROJECT_ID

IBM_WATSONX_URL

Never hardcode credentials.

Provide a complete .env.example file.

Provide detailed setup instructions inside README.md explaining where users should place these values.

Create a dedicated watsonx service module responsible for:

Authentication

Model connection

Prompt execution

Error handling

Retry handling

Timeout handling

The rest of the application should never directly call IBM Granite.

All requests should pass through the service layer.
